# FabAi Studios — Releases

Built desktop releases and the in-app update feed for FabAi Studios. No source code lives here.

Apps check `releases/latest/download/latest.json` and update themselves in-app.

## `marketing-os/`

The FabAi Marketing OS lives in [`marketing-os/`](marketing-os/) — an enterprise marketing
automation system whose n8n workflow estate is compiled from declarative specs rather than
edited on a canvas. It is self-contained and has no bearing on the release feed above.
